# Wallpapers

Ten Tokyo Roadster colourways, ordered wall-ride (default), lineup, hover, ramp, inverted, rear, diffuser, studio, the ROADSTER event poster and Starlight. All are lossless sRGB PNG exports with an 8192-pixel longest edge, upscaled from the native generated artwork with Real-ESRGAN (x4plus, 4x) and fitted to size with Lanczos. No additional two-pass contextual enhancement is claimed. See ../docs/WALLPAPER-GENERATION.json, ../CREDITS.md and ../SHA256SUMS.

Starlight is AI-extended sideways to a 16:9 desktop composition at 8192 × 4608, with the complete car and raised doors in frame.
