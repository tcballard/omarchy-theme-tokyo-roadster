# Wallpapers

Ten Tokyo Roadster colourways, ordered wall-ride (default), lineup, hover, ramp, inverted, rear, diffuser, studio, the ROADSTER event poster and Starlight. The approved wall-ride is preserved byte-for-byte. All are lossless RGB8 PNG exports with an 8192-pixel longest edge. The other nine use Real-ESRGAN x4plus (4x) and a Lanczos fit on previous exports downsampled to recorded native dimensions, not original native generation files. No additional two-pass contextual enhancement is claimed. See ../docs/WALLPAPER-GENERATION.json, ../CREDITS.md and ../SHA256SUMS.

Starlight is AI-extended sideways to a 16:9 desktop composition at 8192 × 4608, with the complete car and raised doors in frame.
